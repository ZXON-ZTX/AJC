# Media and Assets

## Routing

- 新图或图像编辑 → `imagegen`
- 批量照片调整 → `adobe-batch-edit-photos`
- 人像批量修饰 → `adobe-retouch-portraits`
- 产品 Mockup → `adobe-create-mockups`
- 社交平台尺寸/变体 → `adobe-create-social-variations`
- 模板视觉 → `adobe-design-from-template`
- Quick Cut 视频 → `adobe-edit-quick-cut`
- 视频构成、标题卡、字幕、动画 → `hyperframes:hyperframes`
- GSAP 动效 → `hyperframes:gsap`
- 网站转视频 → `hyperframes:website-to-hyperframes`

## Brief Contract

确定主体、目的、受众、平台、尺寸、比例、时长、帧率、分辨率、格式、文本、语言、品牌、版权边界、参考资产和输出目录。区分必需元素与风格偏好。

## Reference Handling

本地目标图像全部可用时，使用本地路径；只存在于对话中的参考图，使用完成任务所需的最少近期图像。编辑未检查的本地素材前先预览。不能假设缺失资产、人物授权、字体授权或音乐授权已经存在。

## Quality Pass

图像检查构图、主体、清晰度、文字、色彩、裁剪、伪影、边缘、透明度和一致性。视频/动画检查首尾帧、节奏、转场、字幕、音画同步、循环和导出。文本视觉必须在最终显示尺寸检查。

## Delivery

区分草稿、最终稿和变体；提供绝对路径、实际格式、尺寸/时长和预览。不要暴露私有参考素材、隐藏元数据、凭据或未授权个人信息。
