# 个人 Skills 技能包

## 数据来源与边界

本技能包依据当前可见的 AGENTS.md、Codex 工具规则、可用技能目录、推荐插件清单、已有个人工作规范和本线程中确认的偏好进行蒸馏：中文沟通、结果先行、主动推进、明确假设、严格范围、精准改动、按风险验证、凭据保护和外部动作先确认。

无法读取的其他历史对话不被当作已分析数据。本公开副本随 AJC Skill Plugin 一同分发，供使用者按需查阅模块细节。

## 组成

| 技能 | 负责范围 |
|---|---|
| `task-orchestration` | 总路由、任务分类、技能组合和控制循环 |
| `requirements-and-scope` | 需求、假设、开放选择、范围和成功标准 |
| `safe-execution-and-verification` | 执行、证据、状态用语和完成核验 |
| `code-engineering` | 代码、TDD、调试、测试、审查和交付 |
| `research-and-evidence` | 浏览判断、来源层级、引用和不确定性 |
| `data-and-reporting` | 数据质量、指标、计算、图表和报告 |
| `documents-and-artifacts` | Word、PDF、表格、演示和云端文件 |
| `design-and-frontend` | 产品设计、Figma、前端、响应式和无障碍 |
| `media-and-assets` | 图片、照片、视频、音频、动画和素材 |
| `plugin-and-connector-routing` | 技能、插件、连接器、安装和能力矩阵 |
| `external-actions-and-automation` | 外部写入、发送、发布、分享、删除、调度和监控 |
| `coordination-and-threads` | 并行任务、Codex tasks、等待、交接和结果合并 |
| `communication-and-output` | 中文表达、结果顺序、状态标签和交付格式 |

## 推荐加载策略

默认只加载：

1. `task-orchestration`
2. 一个主领域技能
3. 必要的安全/验证技能
4. `communication-and-output`（中文请求）

按条件追加：

- 有歧义或范围风险 → `requirements-and-scope`
- 有本地或代码变更 → `safe-execution-and-verification`
- 有插件/云端/发送/发布/删除/调度 → `external-actions-and-automation`
- 有并行或任务交接 → `coordination-and-threads`
- 需要选择插件或工具 → `plugin-and-connector-routing`

## 文件结构

每个技能文件夹内的 `SKILL.md` 是可被 Codex 识别的技能入口。插件矩阵位于：

`插件与连接器路由/references/参考-插件矩阵.md`

## 安装说明

作为原始说明材料，本索引本身不执行安装。若使用者要单独安装某个模块，应先比较同名技能、确认目标目录、保留现有用户配置，并逐个验证。默认保持自动发现；只有明确要求时才改成显式调用。
