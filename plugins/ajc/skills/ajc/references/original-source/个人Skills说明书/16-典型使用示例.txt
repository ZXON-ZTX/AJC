16  典型使用示例

【示例一：修复一个 Bug】

任务路由 → 假设与范围 → 代码任务 → 测试驱动开发 → 验证与收尾。
先复现并写失败测试，确认失败原因，再写最小修复，最后跑目标测试和完整测试。

【示例二：整理一个 Excel 报告】

任务路由 → 数据分析 → 文档与办公文件 → 验证与收尾。
先确认指标定义和数据质量，再修改表格，最后检查公式、格式、合计和实际打开效果。

【示例三：把设计稿做成网页】

任务路由 → 假设与范围 → 设计与前端 → 视觉验证 → 验证与收尾。
先确认受众、尺寸和交互状态，再实现；最后检查响应式、溢出、焦点和错误状态。

【示例四：发送一封邮件或创建日历任务】

任务路由 → 外部操作安全 → 插件路由 → 起草/预览 → 明确授权 → 执行 → 验证。
必须确认账号、收件人、内容、时间、时区、通知策略和重复风险。

【示例五：查一个当前价格或政策】

任务路由 → 研究与网页 → 主要来源核验 → 引用 → 说明截止时间和不确定性。

【示例六：生成一张宣传图】

任务路由 → 媒体生成 → 明确尺寸、文字、风格和参考图 → 生成/编辑 → 以最终尺寸预览 → 交付绝对路径。

【通用收尾句式】

结果：……
文件/外部效果：……
验证：……
未验证或风险：……
下一步：……
