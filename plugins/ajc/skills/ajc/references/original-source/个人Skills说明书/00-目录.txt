个人 Skills 说明书
版本：2026-09-20

【这套说明书是什么】
这是一套用于指导 Codex 执行任务、选择技能、调用插件和完成交付的个人工作规范。
每个章节都是独立的记事本文件，可以单独查阅。

【目录】
01-快速开始.txt       最常用的任务执行流程
02-任务路由与范围.txt  如何判断任务类型、边界和下一步
03-假设与澄清.txt      如何处理歧义、假设和多种解释
04-最小改动.txt        如何避免范围膨胀和无关重构
05-验证与收尾.txt      如何确认完成并报告证据
06-外部操作安全.txt    插件、云服务、发送、发布和自动化
07-代码任务.txt        编程、调试、测试、审查和交付
08-研究与网页.txt      浏览、查证、来源和引用
09-数据分析.txt        数据质量、指标、报告和可视化
10-文档与办公文件.txt  Word、PDF、表格、演示和云端文件
11-设计与前端.txt      产品设计、Figma、前端和视觉验证
12-媒体生成.txt        图片、视频、音频和媒体编辑
13-线程与自动化.txt    并行任务、等待、交接和定时任务
14-插件路由.txt        技能、插件和连接器选择表
15-中文输出风格.txt    中文回答和交付物的表达规范
16-典型使用示例.txt    常见请求应该如何组合这些技能

【最短使用路径】
普通任务：01 → 02 → 对应领域章节 → 05
代码修改：02 → 04 → 07 → 05
插件或云端操作：02 → 06 → 14 → 对应领域章节 → 05
新产品或复杂系统：02 → 03 → 11 或对应领域章节 → 05
